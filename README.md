# Жасанды жүрек технологиясы — конференция

Интерактивті 3D конференция сайты. Басты бет: `index.html`.

## GitHub Pages жариялау

1. Репозиторийдің **Settings → Pages** бөліміне өтіңіз.
2. **Build and deployment → Source** параметрінен **GitHub Actions** таңдаңыз.
3. `.github/workflows/deploy-pages.yml` workflow-ы сайтты автоматты жариялауға арналған.

Жарияланғаннан кейін сайт мына мекенжайда қолжетімді болады:
https://arnurzhetibaev07-cmyk.github.io/jasandy-jurek/

Ескерту: интерактивті 3D көріністер Three.js кітапханасын CDN арқылы жүктейді, сондықтан интернет байланысы қажет. Тіркелу формасы демонстрациялық режимде жұмыс істейді және деректерді серверге жібермейді.
